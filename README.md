### 👨‍💻 Sobre Mim

Cientista da Computação graduado pela **UTFPR**, atuando na convergência entre **Engenharia de Software Full-Stack** e **Engenharia de Dados**. Experiência prática na concepção de sistemas web escaláveis, arquiteturas resilientes e pipelines analíticos de dados.

* **Engenharia de Software:** Desenvolvimento de aplicações web completas, microsserviços e APIs RESTful orientadas a eventos e processamento assíncrono (filas/jobs) no ecossistema PHP moderno (**Laravel** e **Inertia.js**), integrado a interfaces responsivas e dinâmicas com **Vue.js**, **React** e computação gráfica em **Three.js**.
* **Engenharia de Dados & BI:** Modelagem dimensional e implementação de pipelines ETL/ELT sob a **Arquitetura Medalhão** (Bronze, Silver, Gold), governança de dados e análise de conformidade de fluxos com técnicas de **Process Mining** (PM4Py).
* **Pesquisa & Machine Learning Aplicado:** Desenvolvimento de modelos preditivos (Random Forest, Gradient Boosting) e tratamento de dados complexos em projetos de impacto real, incluindo parceria institucional entre **UTFPR & Unimed**.
